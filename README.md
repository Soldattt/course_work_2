# Курсовая работа 
Программа разработана на Python для получения информации о самолетах
## Установка
1. Клонируйте репозиторий:
```
git clone https://github.com/Soldattt/course_work_2.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Описание работы модулей
*Модуль get_api.py*
Классы в модуле получают данные о самолетах в указанной пользователем стране

*Модуль aircraft.py*
Класс Aircraft получает данные из модуля get_api.py, данные для сортировки от пользователя о сортировке самолетов и формирует список самолетов на их основании

*Модуль saver_info.py*
Класс InfoJSON сохраняет данные о самолетах в файл и при необходимости очищает этот файл

*Модуль utils.py*
В модуле собраны методы для сравнения, сортировки самолетов и вывода результата в консоль
